🏎️ Sobre o Projeto

Estatísticas F1 - Análise de dados 1950-2026

📊 O que é este projeto?

Este site foi criado para analisar e visualizar dados históricos da Fórmula 1, cobrindo as temporadas de 1950 a 2026. O objetivo é mostrar estatísticas de vitórias por piloto, por equipe e a evolução ao longo dos anos.

🛠️ Tecnologias utilizadas

🐍 Python 📊 Pandas 📈 Matplotlib 🌐 Flask 🎨 HTML/CSS

Os dados foram coletados através da API Ergast e processados com Python. Os gráficos foram gerados com Matplotlib e o site foi desenvolvido com Flask.

📈 O que você pode encontrar aqui?

  • 🏆 Vitórias por Piloto – Ranking dos pilotos com mais vitórias
  • 🏆 Vitórias por Equipe – Comparativo entre as equipes
  • 📈 Evolução por Temporada – Total de corridas por ano
  • 📊 Tabela Resumo – Números exatos de cada piloto

👨‍💻 Sobre o desenvolvedor

Este projeto foi desenvolvido como parte do aprendizado em programação, com foco em análise de dados e desenvolvimento web. O objetivo é criar um portfólio que mostre habilidades técnicas e paixão por dados.

Tecnologias dominadas: Python, Pandas, Flask, HTML/CSS, Git
